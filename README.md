 # 📊 Student Depression Data Analysis Dashboard

![Tableau Dashboard](student-depression-dashboard.png) 





## 📌 Project Overview


The **Student Depression Data Analysis Dashboard** is an interactive data visualization project created using **Tableau Public**.

The main purpose of this project is to analyze different factors related to student well-being and depression patterns, including **Academic Pressure, Financial Stress, Student Satisfaction, Sleep Duration, and Study Hours**.

The dashboard presents the data in an easy-to-understand visual format and helps identify patterns and differences among students.

---

## 🎯 Project Objectives

- 📚 Analyze the impact of **Academic Pressure** on students.
- 💰 Analyze different levels of **Financial Stress**.
- 😊 Understand **Student Satisfaction** levels.
- 😴 Analyze **Sleep Duration** among students.
- 📖 Analyze **Study Hours** and student distribution.
- 📊 Present all major insights through an interactive Tableau dashboard.

---

## 📈 Dashboard Features

### 📚 Academic Pressure & Student Count

This visualization shows the distribution of students across different levels of academic pressure.

### 💰 Financial Stress & Student Count

This section represents the number of students across different financial stress categories.

### 😊 Student Satisfaction & Student Count

This visualization compares students based on their satisfaction levels.

### 😴 Sleep Duration & Student Count

This section analyzes the distribution of students according to their sleeping duration.

### 📖 Study Hours & Student Count

This visualization shows student distribution across different study-hour categories.
